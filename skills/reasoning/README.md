# Reasoning Protocols (`skills/reasoning/`)

Welcome to the **Reasoning Protocols** category index. This category documents cognitive strategies, decision trees, reflection loops, and formal logic structures used by AI models to solve complex algorithmic tasks.

---

## Category Overview

Reasoning Protocols cover systematic logical frameworks—such as Chain-of-Thought (CoT), Tree-of-Thought (ToT), Reflection Loops, and ReAct loops—that enable models to verify intermediate hypotheses before outputting code.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#7-reasoning-reasoning-protocols).

---

## Target Audience

- AI Researchers and Engineers configuring reasoning models (o1, Claude 3.5, Gemini 1.5).
- Developers building self-correcting code generation pipelines.
- Algorithm designers seeking rigorous multi-step problem solving.
