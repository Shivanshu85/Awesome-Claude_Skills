# Developer Productivity (`skills/productivity/`)

Welcome to the **Developer Productivity** category index. This category documents workflow accelerators, velocity macros, auto-commit generators, pull request summary builders, and developer shortcuts.

---

## Category Overview

Productivity skills focus on reducing developer toil. By automating repetitive task boilerplate, generating Git commit messages, writing PR summaries, and streamlining release notes, these skills accelerate developer velocity.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#16-productivity-developer-productivity).

---

## Target Audience

- Software Engineers seeking velocity optimizations for daily workflows.
- Team Leads standardizing PR summaries and commit message formatting.
- Developers looking to reduce manual task overhead.
