# Agent Frameworks (`skills/agent-frameworks/`)

Welcome to the **Agent Frameworks** category index. This category documents multi-agent topologies, supervisor-agent orchestration patterns, peer swarms, and delegation architectures for complex coding tasks.

---

## Category Overview

Agent Frameworks skills cover multi-agent coordination architectures where specialized AI agents (e.g. planner, coder, reviewer, tester) collaborate under supervisor or peer-to-peer topologies to execute end-to-end engineering tasks.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#14-agent-frameworks-agent-frameworks).

---

## Target Audience

- AI Systems Architects designing multi-agent software engineering teams.
- Developers orchestrating sub-agent delegation workflows.
- Framework maintainers building open-source agent swarms.
