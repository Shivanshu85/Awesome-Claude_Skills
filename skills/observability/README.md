# Observability & Tracing (`skills/observability/`)

Welcome to the **Observability & Tracing** category index. This category documents token usage tracking, span tracing, OpenTelemetry integrations, execution logging, and latency monitoring for AI agent systems.

---

## Category Overview

Observability skills provide visibility into the black box of LLM agent execution. This includes tracking token counters, inspecting prompt/response latency, capturing tool-call spans, and debugging agent execution failures.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#13-observability-observability--tracing).

---

## Target Audience

- System Administrators monitoring LLM API cost and token budgets.
- AI Engineers debugging agent execution loops and tool call failures.
- Observability engineers implementing OpenTelemetry spans for LLMs.
