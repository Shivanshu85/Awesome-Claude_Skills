# Developer Tools (`skills/developer-tools/`)

Welcome to the **Developer Tools** category index. This category documents CLI wrappers, terminal bridges, developer helper scripts, and inspection tools designed to enhance interaction between developers and AI coding agents.

---

## Category Overview

Developer Tools skills focus on local utilities, terminal bridges, process managers, and interactive inspectors that give developers fine-grained control and visibility into AI agent operations.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#8-developer-tools-developer-tools).

---

## Target Audience

- Software engineers looking for CLI shortcuts and agent inspection utilities.
- DevRel engineers demonstrating local AI coding workflows.
- Maintainers building interactive agent toolkits.
