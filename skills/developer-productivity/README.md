# Developer Productivity (`skills/developer-productivity/`)

Welcome to the **Developer Productivity** category index. This category documents workflow acceleration tools, developer macros, CLI companions, and automation scripts that streamline AI-assisted software development.

---

## What is Developer Productivity?

Developer Productivity tools eliminate repetitive friction in AI-driven coding. They bridge local developer environments (terminal, IDE, git) with AI assistants, enabling instant command generation, rapid context switching, and automated workflow triggers.

---

## Why Developer Productivity Matters

- **Maximizes Developer Velocity**: Reduces manual copy-pasting between terminal output, IDE buffers, and assistant chat windows.
- **Automates Boilerplate Tasks**: Automates PR description generation, release note drafting, and commit message formatting.
- **Unifies Terminal & Assistant**: Connects CLI terminal sessions directly to AI assistant workflows.

---

## When to Use Developer Productivity

- When configuring CLI helpers or terminal-bound AI assistants.
- When setting up repository macros for rapid context injection.
- When automating developer workflow triggers in local dev environments.

---

## Recommended Learning Order

1. **CLI Assistant Companions**: Binding AI triggers to terminal shortcuts.
2. **Workflow Automation**: Generating PR descriptions, commit messages, and docs automatically.
3. **IDE Macro Optimization**: Fine-tuning shortcuts for Claude Code, Cursor, and Windsurf.
