Overview

Mem0 ("mem-zero") provides a self-improving memory layer for LLM applications and AI coding assistants. Unlike basic chat history buffers that dump full conversation transcripts into the prompt window, Mem0 extracts facts, entity relationships, and user preferences into a structured, queryable memory graph.

Multi-Layer Scope

Partition memory seamlessly across User, Session, and Agent scopes for granular retrieval.

Hybrid Parallel Search

Combines vector embeddings, BM25 keyword match, and entity linking for high-precision recall.

Temporal Reasoning

Time-aware scoring accurately handles queries about past choices, current state, and future plans.

Architecture & Workflow

Mem0 operates as an intermediate memory controller sitting between the application prompt loop and vector/graph storage layers.

Configuration Options

Mem0 supports custom configuration for vector databases (Qdrant, Pinecone, Milvus, PGVector), LLM models (OpenAI, Anthropic, Gemini, Ollama), and embedding providers.

config = {

        "config": {
            "host": "localhost",
            "port": 6333,
        }
    },
    "llm": {
        "provider": "openai",
        "config": {
            "model": "gpt-4o",
            "temperature": 0.0
        }
    },
    "embedder": {
        "provider": "openai",
        "config": {
            "model": "text-embedding-3-small"
        }
    }
}

Code Examples

Python Basic Example

from mem0 import Memory

# 1. Initialize Memory Client
m = Memory()

# 2. Add memories for a user or coding session
m.add(
    "User prefers TypeScript with strict mode and uses Tailwind CSS",
    user_id="dev_user_101"
)

# 3. Search relevant memory context
relevant = m.search(
    query="What styling library does the user prefer?",
    user_id="dev_user_101"
)

print(relevant)

Node.js / TypeScript Example

import { Memory } from "mem0ai";

const memory = new Memory();

async function run() {
  await memory.add([
    { role: "user", content: "I am building a React project using Vite and Vitest." }
  ], { userId: "dev_user_101" });

  const result = await memory.search("What testing tool is being used?", {
    userId: "dev_user_101"
  });

  console.log(result);
}

run();

Best Practices & Recommendations

Recommended: Always provide explicit user_id or agent_id scope flags when storing memory to ensure isolation between multi-tenant users or coding tasks.
Anti-Pattern: Avoid storing secrets, API keys, or raw JWT tokens inside memory instances. Always sanitize inputs before calling memory.add().

Troubleshooting & FAQ

Q: How does Mem0 prevent memory degradation over time?

Mem0 uses single-pass fact extraction and entity linking. Rather than performing destructive updates on existing records, new memories accumulate with temporal timestamps, and multi-signal scoring ranks recent relevant memories first.

Q: Can Mem0 run completely offline locally?

Yes. Mem0 supports local vector stores like Qdrant/Chroma and local LLMs via Ollama for air-gapped environments.
