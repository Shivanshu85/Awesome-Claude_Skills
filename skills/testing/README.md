# Automated Testing (`skills/testing/`)

Welcome to the **Automated Testing** category index. This category documents AI-assisted test generation, dynamic unit test execution, assertion verification, and automated test-driven development (TDD) loops.

---

## Category Overview

Testing skills focus on verifying synthesized code through automated test generation, test runner integration (pytest, jest, vitest), coverage verification, and assertion loops to guarantee correctness before code merge.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#11-testing-automated-testing).

---

## Target Audience

- QA and Automation Engineers integrating AI test generation tools.
- Developers practicing AI-assisted Test-Driven Development (TDD).
- Maintainers building automated test verification bots.
