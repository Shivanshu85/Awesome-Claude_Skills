# LLM Evaluation (`skills/evaluation/`)

Welcome to the **LLM Evaluation** category index. This category documents benchmark frameworks, eval datasets, scoring metrics (pass@k, accuracy), and LLM-as-a-judge protocols for assessing AI coding performance.

---

## Category Overview

Evaluation skills provide quantitative and qualitative frameworks for benchmarking AI models, prompt strategies, and agent tool-use accuracy on standardized software engineering datasets (e.g. HumanEval, SWE-bench).

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#12-evaluation-llm-evaluation).

---

## Target Audience

- AI Researchers measuring model capabilities across coding benchmarks.
- Enterprise Teams evaluating model selection for AI coding assistants.
- Evaluation framework maintainers.
