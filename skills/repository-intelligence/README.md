# Repository Intelligence (`skills/repository-intelligence/`)

Welcome to the **Repository Intelligence** category index. This category documents AST parsing, file bundling, codebase mapping, call-graph extraction, and repository packing tools (such as Repomix).

---

## Category Overview

Repository Intelligence skills analyze codebases at structural levels. By generating Abstract Syntax Trees (ASTs), mapping file dependencies, and packing repository files into clean Markdown/XML representations, these tools enable LLMs to understand complex software architectures.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#9-repository-intelligence-repository-intelligence).

---

## Target Audience

- Developers working with large legacy repositories.
- AI Engineers configuring repository indexing and AST extraction pipelines.
- Open-source maintainers packing project files for AI code generation.
