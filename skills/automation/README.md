# Automation (`skills/automation/`)

Welcome to the **Automation** category index. This category documents autonomous execution loops, background agent triggers, CI/CD pipeline AI integrations, and background refactoring scripts.

---

## Category Overview

Automation skills bridge human requests with autonomous execution scripts. This covers background worker loops, cron-triggered repository audits, auto-fixing pull request agents, and automated release pipeline integrations.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#5-automation-automation).

---

## Target Audience

- DevOps and Platform Engineers embedding AI agents into CI/CD pipelines.
- AI Engineers orchestrating background autonomous code maintenance loops.
- Developers automating repetitive repository administrative tasks.
