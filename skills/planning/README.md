# Task Planning (`skills/planning/`)

Welcome to the **Task Planning** category index. This category documents frameworks, protocols, and templates for breaking down complex software engineering objectives into structured, step-by-step implementation plans.

---

## Category Overview

Before making code edits, complex engineering tasks require architectural planning. Planning skills focus on generating step-by-step implementation plans, milestone checklists, DAG dependency graphs, and user review checkpoints.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#6-planning-task-planning).

---

## Target Audience

- Technical Leads and Architects defining structured AI task decomposition rules.
- AI Engineers creating planning phases for agentic software execution.
- Developers looking to improve code edit accuracy through upfront planning.
