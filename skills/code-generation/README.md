# Code Generation (`skills/code-generation/`)

Welcome to the **Code Generation** category index. This category documents code synthesis, pattern transformation, boilerplate generation, and migration templates for AI coding assistants.

---

## Category Overview

Code Generation skills focus on pattern transformation, framework migrations, boilerplate synthesis, and architectural refactoring rules. These skills define optimal prompts and structural constraints to synthesize high-quality code.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#17-code-generation-code-generation).

---

## Target Audience

- Software Engineers performing major codebase refactorings or framework migrations.
- AI Prompt Engineers optimizing code synthesis quality.
- Library Maintainers creating code synthesis templates for their SDKs.
