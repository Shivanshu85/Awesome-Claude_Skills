# AI IDE Integrations (`skills/ai-ides/`)

Welcome to the **AI IDE Integrations** category index. This category documents configuration rules, native skill formats, and setup guidelines for AI-native IDEs (Cursor, Claude Code, Windsurf, VS Code extensions).

---

## Category Overview

Modern IDEs provide native configuration interfaces (`.cursorrules`, `.clauderc`, `.windsurfrules`). This category documents how to format rules, expose local tools, and optimize editor settings for seamless AI-assisted coding.

For detailed domain boundaries and inclusion rules, see [docs/taxonomy.md](file:///docs/taxonomy.md#15-ai-ides-ai-ide-integrations).

---

## Target Audience

- Developers using Cursor, Claude Code, Windsurf, or VS Code AI plugins.
- Engineering managers establishing organization-wide `.cursorrules` standards.
- Plugin developers integrating custom AI extensions into IDE editors.
