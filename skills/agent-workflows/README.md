# Agent Workflows (`skills/agent-workflows/`)

Welcome to the **Agent Workflows** category index. This category documents multi-step reasoning protocols, task decomposition techniques, reflection loops, ReAct frameworks, and sequential thinking patterns for AI coding assistants.

---

## What is Agent Workflows?

Agent Workflows focus on cognitive structuring for AI assistants. Instead of generating code in a single unverified leap, agent workflow protocols guide models through step-by-step planning, dynamic hypothesis testing, self-reflection, and solution verification before committing code edits.

---

## Why Agent Workflows Matters

- **Prevents Superficial Coding Mistakes**: Forces the assistant to reason through edge cases and dependencies before modifying files.
- **Reduces Hallucinated Fixes**: Implements self-reflection and execution verification loops.
- **Tackles Complex Refactoring**: Decomposes large engineering goals into manageable, verifiable sub-tasks.

---

## When to Use Agent Workflows

- When instructing AI assistants to perform multi-file refactoring or architecture redesigns.
- When debugging complex, non-obvious runtime errors or memory leaks.
- When configuring autonomous agentic loops requiring plan approval and milestone tracking.

---

## Recommended Learning Order

1. **Step-by-Step Task Decomposition**: Breaking large tasks into discrete milestones.
2. **Sequential Thinking Protocols**: Dynamic reasoning trees using tools like Sequential Thinking MCP.
3. **Reflection & ReAct Loops**: Self-evaluating intermediate outputs against test assertions.
